# ai-analysis-brazil-sedimentary-basins 🚀

> O uso do NotebookLM tem, aqui, como finalidade a ingestão de fontes ligadas à geologia, que vão desde temas como estrutura, estratigrafia e evolução tectono-sedimentar das bacias sedimentares brasileiras a possíveis reservas mineralógicas. Com isso, o prompt fornece resultados a perguntas sobre questões relativas a tais eventos, estruturas e recursos.

## 🛠️ Tecnologias Utilizadas
As principal tecnologa usada para construir o projeto:
* NotebookLM
